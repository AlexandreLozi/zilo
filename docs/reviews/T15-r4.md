## Findings

1. **P2 — Escape recovery overrides intentional host cancellation, even outside Zilo content.**
   `packages/ui/src/dialog.ts:654–656,673–679,755–763`;
   `packages/ui/README.md:139–143,180–184`.
   A document capture listener calling `preventDefault()` cannot reveal whether the host means
   “keep my parent open but close the child” or “keep this native modal open.” Zilo assumes the
   former and actively requests closure in window bubble. There is no containment or opt-in check:
   even an unrelated native dialog appended to `body`, above Zilo, is closed against its owner's
   explicit Escape cancellation. The README states a broad rule, not an inside-Zilo-only boundary;
   documenting that broad rule does not make overriding another modal's policy safe.
   **Evidence:** `apps/catalog/e2e/review-r4.spec.ts`, first test, fails in Chromium and Firefox
   with zero retries: the separate host dialog loses `open` despite document capture cancellation.
   Its focused button is inside a nested non-layer `<section>`, so ancestor traversal is exercised.
   Prefer explicit host dismissal/opt-in for the Radix workaround; do not infer dismissal consent
   from cancellation alone. Existing r3 proof expectations must be reconciled with that contract.

2. **P2 — Recovery can close the wrong, older native layer beneath Zilo.**
   `packages/ui/src/dialog.ts:600–603,617–620,654–656,677–678`.
   The event-time model intentionally classifies a focused older native child as newer, relying
   on the browser to close the actual topmost dialog (Zilo) instead. The recovery path then uses
   that approximate classification as an exact dismissal target. When document capture cancels
   Escape, it closes the older child, although native default would close neither layer after
   cancellation, or the topmost Zilo without cancellation. This breaks the stated “as the browser
   would” rule and can dismiss underlying content the user was not dismissing.
   **Evidence:** the second r4 proof opens a native child first, then Zilo with initial focus in
   that child's nested button, and cancels Escape in document capture. Chromium and Firefox both
   lose the child's `open` attribute. The existing uncancelled older-child test passes, but does
   not cover this interaction. Do not apply an active-close fallback to a layer whose top-layer
   order is unknown.
