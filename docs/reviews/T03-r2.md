## Actionable finding

### 1. Medium — absent Run values crash the Windows uninstall assertions

**Path:** `packaging/windows/install-smoke.ps1:61` (strict mode enabled at line 10).

After successful uninstall and the install-directory absence check, the smoke evaluates
`(Get-ItemProperty $runKey -ErrorAction SilentlyContinue).PSObject.Properties.Name`.
On this hosted runner the empty/absent result does not provide a `Name` property under strict
mode. The step throws **“The property 'Name' cannot be found on this object. Verify that the
property exists.”** instead of recognizing the valid absence of `ZiloAgent`.

This is observed, not hypothetical: exact-head Windows job
[124655230271](https://github.com/AlexandreLozi/zilo/actions/runs/41241182388/job/124655230271)
logs install files, marker, Run/protocol values and the expected scaffold output, then
`=== uninstall`, this exception at `2026-10-31T20:57:10.8211447Z`, and exit 1. The unchanged
line existed before this fix, but the formerly broken build path had prevented reaching it.
The newly required owned-key removal and sibling sentinel checks at lines 62–67 are therefore
**not executed**, and `MSI SMOKE PASS` is absent. This does not establish that uninstall itself
is broken; it establishes that its acceptance smoke is broken.

**Required correction:** make the Run-value absence assertion explicitly null/empty-safe while
preserving strict mode and failure on an actually retained `ZiloAgent` value. Cover an absent
Run key, an existing Run key without `ZiloAgent`, and a key retaining `ZiloAgent`; the first two
must continue, and the last must fail. Then obtain coordinator-approved exact-corrected-head
hosted evidence through the normal author push, with owned marker/protocol removal,
`sibling sentinel survived uninstall`, and `MSI SMOKE PASS`. This review triggered no rerun.
