# T04a — Web scaffold (FE lane, Claude author, GPT reviewer)

**Target:** the front-end monorepo skeleton. Implements D-009 (read `docs/planning/DECISIONS.md` D-009
and `docs/planning/PLAN.md` §3).

**Change:**
- A root `package.json` with a pnpm workspace (`pnpm-workspace.yaml`) and Node LTS pinned through
  `engines` and `.nvmrc`.
- Packages:
  - `packages/sdk` (`@zilo/sdk`): ESM, no runtime deps, `src/index.ts` exporting a `version`
    constant;
  - `packages/ui` (`@zilo/ui`): Web Components, with Lit allowed as the only runtime dep if you
    justify it, otherwise vanilla. Placeholder `<zilo-placeholder>`;
  - `packages/dwt-compat` (`@zilo/dwt-compat`): an empty stub with a README saying it is blocked on the
    owner's code.
- `apps/demo`: Vite + TS that imports the SDK and UI and renders a placeholder.
- Tooling:
  - shared `tsconfig.base.json` with strict mode, `noUncheckedIndexedAccess` and
    `exactOptionalPropertyTypes`;
  - ESLint (flat config) and Prettier;
  - Vitest per package, with one trivial test each;
  - Playwright config in `apps/demo/e2e` (chromium, firefox, webkit) with one smoke test that loads
    the demo.
- `.github/workflows/ci-web.yml`: install with a frozen lockfile, then lint, typecheck, test, build,
  and the Playwright smoke on ubuntu-latest.
- A licence check for npm dependencies: deny GPL, AGPL and unknown licences by default (for example
  with `license-checker-rseidelsohn` or an equivalent), wired into `ci-web`.

**Constraints:**
- No backend files.
- Do not create `.github/workflows` files other than `ci-web.yml`.
- Keep dependencies minimal and pin exact versions.
- `pnpm-lock.yaml` is committed.

**Allowed files:** `package.json`, `pnpm-workspace.yaml`, `pnpm-lock.yaml`, `.npmrc`, `.nvmrc`,
`tsconfig*.json`, `eslint.config.*`, `.prettier*`, `packages/**`, `apps/**`,
`.github/workflows/ci-web.yml`, root `.gitignore` (append-only).

**Observable acceptance:** `pnpm install --frozen-lockfile && pnpm -r lint typecheck test build`
passes locally, and the Playwright smoke passes. Report the exact commands and output in the
`worker_done` summary.
