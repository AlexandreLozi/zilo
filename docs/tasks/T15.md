# T15 UI foundation (Claude author; effort medium)

**Deps (merged):** T04a (web scaffold), T05 (design spec).

**Binding:** CLAUDE.md, BRIEF, OWNER-DIRECTIVES (OD-4 headless, OD-8 React-first wrapper over
framework-agnostic Web Components, OD-9), PLAN §3 (`packages/ui`: Web Components + React wrapper,
themable, WCAG 2.2 AA), EXECUTION §3 T15 and §3a, D-009. Design source: `docs/design/**` (tokens.md,
accessibility.md, scan-dialog.md, detection-dialogs.md) and `design/prototypes/**`. Don't copy
prototype code wholesale; implement it properly.

**Change:**
1. **`@zilo/ui`** (`packages/ui`): a framework-agnostic Web Components base.
   - Plain custom elements with no runtime framework dependency, unless the gain is clear and you
     write down why. If you add Lit, its licence must pass the gate.
   - Shadow DOM, attribute and property reflection, typed `CustomEvent`s.
   - Design tokens from `tokens.md` as CSS custom properties, with light, dark and system themes,
     and a documented theming API (custom properties or `::part`).
   - **A dialog primitive:** modal, focus trap, initial and return focus, Escape and close, inert
     background, ARIA (`role=dialog`, `aria-modal`, labelling), scroll lock and reduced motion.
   - A minimal button, a banner/alert with live-region semantics, and a spinner/progress.
   - Remove the placeholder.
2. **`@zilo/react`** (new `packages/react`): the first-class React (TSX) wrapper.
   - Typed props, mapped event callbacks and ref forwarding.
   - Tests with React Testing Library.
   - React is a peer dependency. React 19 is preferred if the lint and typecheck setup allows it.
3. **Component catalog** (new `apps/catalog`, Vite + TS): one page per component and state, in
   both themes. Playwright headless with `@axe-core/playwright`: 0 violations on every catalog state
   in Chromium, Firefox and WebKit, plus keyboard tests of the dialog's focus trap and return.
4. Wire the new workspace packages into the pnpm workspace and the root scripts. Extend `ci-web.yml`
   only as needed to run the catalog e2e. Keep `ci-web` a single Linux job.

**Constraints:**
- Strict TS, existing lint and format rules, licence gate green. Add only the dependencies the work
  needs.
- **You own `pnpm-lock.yaml` for this period.** T13 is pre-authored in parallel and must not add
  dependencies.
- No SDK or network code; that is T13.
- Headless only; no native Windows runs.

**Allowed files:** `packages/ui/**`, `packages/react/**`, `apps/catalog/**`, `pnpm-workspace.yaml`,
`pnpm-lock.yaml`, root `package.json` scripts, `tsconfig*.json`, `eslint.config.*`, `.prettierignore`,
`.github/workflows/ci-web.yml`, `docs/validation/logs/T15/**`.

**Observable acceptance:**
- Locally: `pnpm install --frozen-lockfile && pnpm license-check && pnpm format:check && pnpm -r lint && pnpm -r typecheck && pnpm -r test && pnpm -r build`,
  then `CI=1 pnpm e2e` (local WebKit may be blocked by missing host libraries; say so).
- Hosted `ci-web` green on the pushed head. ci-web runs on `pull_request`, so open a **draft PR**
  `t15-ui-foundation` → `main` titled "T15 (draft, CI evidence only)"; merges go through the Opus
  queue.
- `worker_done` gives the head SHA, the CI run URL and the counts.
