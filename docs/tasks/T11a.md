## Review focus
1. A T10-valid64-character JobId versus the spike's40-character bound; production index0 versus
   human/prototype page1; immutable acquisition identity and duplex side.
2. Cancellable async acquisition with consumer backpressure, no unbounded materialization.
3. Page-content lifetime/ownership (never return a reused or disposed buffer), typed failure after
   prior pages, cancellation distinct from scanner failure.
4. Source-specific caps/default/effective setting shapes, unknown response values retained safely.
5. Domain boundary must not own auth/token/job state, temp storage, export, scheduler or HTTP.
