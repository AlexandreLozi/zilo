**Change** (`packages/sdk`, framework-agnostic TS, no UI):
1. **D-008 detection state machine**, with explicit states and transitions matching the T05 detection
   states (`docs/design/detection-dialogs.md`):
   - not-installed, unreachable-or-blocked, permission states, consent-pending, outdated, ready.
   - Port probing per CONTRACT, with `hello` identifying Zilo so the SDK never talks to a foreign
     service.
2. **Permission query** for the browser's local-network or loopback permission, where it is
   available, with graceful fallback.
3. **HTTP transport:**
   - fetch-based, bounded timeouts and abort;
   - token attach, using the origin-bound token family from D-004a;
   - typed errors for every contract error code (§9);
   - redacted debug logging.
4. **Auth and consent client:**
   - public `hello`, then `POST /auth/consent` with polling via `GET /auth/consent`, then
     `POST /auth/token`;
   - token storage per origin (storage adapter interface, in-memory default);
   - rotation keeps the family.
5. **Devices and caps:** `GET /devices`, refresh (`POST` then `GET`), and caps, with **unknown-field
   and unknown-enum tolerance** (open `ResolutionCaps`, unknown values survive decoding) per the
   contract.
6. **Lost-session (§12):**
   - track the authenticated `HelloFull.instanceId`;
   - on a change, mark the SDK's own jobs `agent-restarted` (retryable), SDK-local only;
   - no automatic rescan; an unknown job gets a typed 404.
7. **Types** generated from `api/openapi.yaml` with the same pinned tooling T10 uses
   (`api/tools/check.sh`), committed or built under `packages/sdk`.
