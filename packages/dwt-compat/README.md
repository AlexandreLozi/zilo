# @zilo/dwt-compat

**Status: blocked on the owner's code.**

This package will hold an optional, thin adapter that maps the Dynamic Web TWAIN calls the owner's
web app actually uses onto `@zilo/sdk`. Which calls to cover depends on the app's integration code,
which the owner has offered to provide (see `docs/context/BRIEF.md` and decision D-006). Until then
the package is an empty stub so the workspace layout, build and CI are in place.
