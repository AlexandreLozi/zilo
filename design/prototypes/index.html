Zilo design prototypes (T05)

Static, self-contained prototypes for every user-facing Zilo surface. Open any file directly from disk. Each page has a control bar to switch state, theme and platform; the state lives in the URL so it can be linked and scanned with axe. The written spec is in docs/design/.

Scan dialog

Scanners with driver badges, capability-bound settings, progress, live thumbnails with rotate, reorder and delete, export, every error code.

docs/design/scan-dialog.md

Detection dialogs

Checking, permission denied with per-browser help, Install (unreachable or blocked), consent wait, Update, Safari paths.

docs/design/detection-dialogs.md

Tray and menu-bar agent

Spoof-resistant consent prompt, allowed sites with revoke, status menu, quit and logs, on Windows, macOS and Linux.

docs/design/tray-agent.md

Design tokens

Colour, type, spacing, radius, elevation and motion for light and dark themes, plus the host theming API.

docs/design/tokens.md
Copy for every state and error code: docs/design/copy.md (generated from assets/copy.js). Accessibility: docs/design/accessibility.md. Checks: design/prototypes/check/run.sh.
