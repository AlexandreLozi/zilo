Host theming

The host sets public tokens on the component element. Here a host uses a violet accent, larger radii and its own font. Hover and subtle tints derive from the accent with color-mix(). If the host's accent is light, it must also set --zilo-color-on-accent and keep 4.5:1.

/* Host app CSS */
zilo-scan-dialog {
  --zilo-color-accent: #5b3cc4;
  --zilo-color-on-accent: #ffffff;
  --zilo-radius-md: 10px;
  --zilo-radius-lg: 16px;
  --zilo-font-sans: Georgia, serif;
}
.app-dark zilo-scan-dialog {
  --zilo-color-accent: #b9a6ff;
  --zilo-color-on-accent: #1d1246;
}
<zilo-scan-dialog theme="auto">
